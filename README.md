# Тема проекта: Разработка RESTful API для интернет-магазина с системой пользователей, корзиной покупок и административной панелью

# Технологический стек:

Бэкенд: Go 1.21

База данных: PostgreSQL 17

Контейнеризация: Docker + Docker Compose

Маршрутизация: Gorilla Mux

API: RESTful JSON API

Тестирование: Встроенные тесты Go и Python тесты

Внешняя зависимость: OpenWeatherMap API

# Этапы разработки
## 1. Определение проблемы 
Пользователи современных интернет-магазинов сталкиваются с проблемой отсутствия единой платформы, которая объединяет удобный просмотр товаров, персонализированные списки избранного, управление корзиной покупок и административные функции управления каталогом в одном решении. Существующие решения часто требуют использования нескольких сервисов или не предоставляют достаточного уровня кастомизации для владельцев магазинов.

## 2. Выработка требований: Пользовательские сценарии:

Регистрация и аутентификация пользователей

Как новый пользователь, я хочу зарегистрироваться в системе, указав email и пароль, чтобы получить доступ к персонализированным функциям магазина

Как зарегистрированный пользователь, я хочу войти в систему, чтобы получить доступ к своему профилю, избранному и корзине

Просмотр и управление товарами

Как покупатель, я хочу просматривать каталог товаров с пагинацией, чтобы находить интересующие меня продукты

Как покупатель, я хочу видеть детальную информацию о товаре, включая описание, цену и изображения, чтобы принять решение о покупке

Как покупатель, я хочу добавлять товары в избранное, чтобы сохранить их для будущего просмотра

Управление корзиной покупок

Как покупатель, я хочу добавлять товары в корзину с указанием количества, чтобы подготовить заказ

Как покупатель, я хочу изменять количество товаров в корзине и удалять ненужные позиции

Как покупатель, я хочу видеть общую сумму заказа и количество товаров в корзине

Административное управление

Как администратор магазина, я хочу управлять каталогом товаров (создание, редактирование, удаление), чтобы поддерживать актуальность ассортимента

Как администратор, я хочу просматривать полный список товаров с детальной информацией

## 3. Контракты API:
Основные endpoints:

GET /api/products - Получение товаров с пагинацией

POST /api/login - Аутентификация пользователя

GET /api/cart - Получение корзины

POST /api/admin/products - Создание товара (только админ)

## 8. Сборка и запуск
Одной командой:
```
docker-compose up --build
```

Остановить всё
```
docker-compose down
```
Что запускается:

PostgreSQL - база данных на порту 5432

Go сервер - API на порту 8080

Веб-интерфейс - доступен по http://localhost:8080

Для тестов:

```
go test ./...
```

```
docker-compose run backend go test ./...
```

## 9. Как использовать
Установите Docker

Склонируйте проект:

