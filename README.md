Modernovo - Интернет-магазин с Go бэкендом
Modernovo - это полнофункциональный интернет-магазин с RESTful API бэкендом на Go, использующий PostgreSQL в качестве базы данных и Docker для контейнеризации.

🚀 Быстрый старт
Предварительные требования
Docker и Docker Compose

Go 1.21+ (для локальной разработки)

Запуск с Docker
Клонируйте репозиторий:

bash
git clone <repository-url>
cd modernovo
Запустите проект:

bash
docker-compose up --build
Приложение будет доступно по адресу:

Бэкенд API: http://localhost:8080

База данных: localhost:5432

Локальная разработка
Установите зависимости:

bash
go mod download
Запустите PostgreSQL локально или используйте Docker контейнер:

bash
docker-compose up postgres
Запустите сервер:

bash
go run GoBackend/cmd/main.go
🔧 API Endpoints
Аутентификация
POST /api/register - Регистрация пользователя

POST /api/login - Вход в систему

POST /api/logout - Выход из системы

GET /api/profile - Получить профиль

PUT /api/profile - Обновить профиль

Товары
GET /api/products - Получить список товаров (с пагинацией)

GET /api/products/{id} - Получить информацию о товаре

GET /api/products/{id}/detail - Детальная информация о товаре

Избранное
GET /api/favorites - Получить список избранных товаров

POST /api/favorites - Добавить товар в избранное

DELETE /api/favorites - Удалить товар из избранного

GET /api/favorites/check - Проверить, находится ли товар в избранном

Корзина
GET /api/cart - Получить корзину

POST /api/cart - Добавить товар в корзину

PUT /api/cart - Обновить количество товара

DELETE /api/cart - Удалить товар из корзины

POST /api/cart/clear - Очистить корзину

Административные функции
GET /api/admin/products - Получить все товары (только для админа)

POST /api/admin/products - Создать товар

PUT /api/admin/products/{id} - Обновить товар

DELETE /api/admin/products/{id} - Удалить товар

Дополнительные
GET /api/weather - Получить погодные данные
